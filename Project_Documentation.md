# Student Performance Analytics System

## 1. Project Title
Student Performance Analytics System using Python, NumPy and Pandas.

## 2. Objective
The objective of this project is to analyze student academic performance using Python. It calculates total marks, average marks, grades, pass/fail status and subject-wise performance. It also identifies the top-performing students.

## 3. Technologies Used
- Python
- NumPy
- Pandas
- CSV dataset
- GitHub

## 4. Dataset Description
The project uses a CSV dataset named `students.csv` containing 20 student records. The dataset includes Student ID, Name, Department, Maths marks, Python marks, Statistics marks and Attendance.

## 5. Implementation
1. The dataset is loaded using Pandas.
2. The subjects are selected for analysis.
3. Functions calculate total marks, average marks and grades.
4. A loop assigns grades to students.
5. NumPy is used to determine pass/fail status.
6. Pandas calculates overall class statistics.
7. Subject-wise averages are calculated using NumPy.
8. The top three students are identified based on average marks.

## 6. Key Features
- Student dataset management
- Total marks calculation
- Average marks calculation
- Automatic grade assignment
- Pass/fail identification
- Highest and lowest average calculation
- Overall class average
- Subject-wise performance analysis
- Identification of top three performers

## 7. Output
The program displays student details, total marks, average marks, grades and pass/fail results. It also displays the class summary, subject-wise averages and top-performing students.

## 8. Final Outcome
The project successfully demonstrates how Python, NumPy and Pandas can be used to analyze student academic data and generate meaningful performance summaries.

## 9. Challenges and Learning
This project helped develop practical knowledge of CSV file handling, Pandas DataFrames, NumPy calculations, Python functions, loops, conditional statements and data analysis. Testing the program helped verify that the analysis runs successfully.
